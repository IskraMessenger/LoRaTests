Silicon Labs CP210x VCP driver (Heltec WiFi LoRa 32 USB-UART).

Source folder: Downloads\heltec2
Archive: heltec2-CP210x-VCP.zip

Install (x64):
1. Unpack the zip
2. Run CP210xVCPInstaller_x64.exe as Administrator
3. Replug the board — Device Manager should show
   "Silicon Labs CP210x USB to UART Bridge (COMx)"
